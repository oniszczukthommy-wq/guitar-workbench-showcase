# 弦间 · 虚拟吉他弹唱工具

**用键盘、触屏或摄像头手势，完成和弦切换与吉他扫弦。**

面向个人弹唱练习的浏览器原型，组合虚拟琴弦、和弦控制、弹唱谱和录音功能。

## 核心体验

- 键盘切换和弦、上下扫弦，鼠标与触屏逐弦弹奏。
- 浏览器内摄像头手势识别：选择和弦、挥手或捏合触发扫弦。
- 可选自动分解和弦，调整速度、音量、空间感和力度。
- 导入 ChordPro／JSON、手动编辑、移调与全屏看谱。
- 按需开启麦克风，把歌声与虚拟吉他混音录制、试听和下载。

## 实现与边界

Tone.js 负责发声与音频处理，MediaPipe 手部识别在浏览器内运行；本机分析接口集成 Chordino、Omnizart 与 Basic Pitch。各第三方组件遵循自身许可。

摄像头画面在浏览器内处理。手机摄像头需要可信 HTTPS，普通局域网 HTTP 可使用触屏演奏等功能。自动和弦与时间轴仍需人工核对，实际手势稳定性需要在设备上验收。
