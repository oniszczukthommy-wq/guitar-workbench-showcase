# 弦间 · 虚拟吉他弹唱工具

浏览器内的虚拟吉他练习原型，支持键盘与触屏弹奏、和弦切换、摄像头手势和录音；音频识别等功能需要额外安装本地依赖。

本仓库包含最新源码及运行资源，不含个人曲库、录音和本机配置。Windows 启动说明见 [WINDOWS.md](WINDOWS.md)，macOS 和功能边界见 [README.txt](README.txt)。摄像头、麦克风与可选分析模型需要在实际设备上验证。

使用的第三方音源、模型和代码按其各自许可分发，来源与许可证见 `vendor/` 和 `source-pins.json`。可以通过 GitHub 的 **Code → Download ZIP** 下载，或克隆本仓库。
